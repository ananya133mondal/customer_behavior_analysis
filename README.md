# Customer Shopping Behavior Analysis

**Author:** Ananya Mondal

## 1. Project Overview

This project analyzes customer shopping behavior using transactional data from **3,900 purchases** across different product categories. The objective is to identify customer spending patterns, product preferences, customer segments, and subscription behavior to generate actionable business insights.

The project follows an end-to-end data analytics workflow, including data cleaning and exploratory data analysis in Python, business analysis using PostgreSQL, and the creation of a final report and PowerPoint presentation.

## 2. Dataset

- **Dataset:** Customer Shopping Behavior
- **Records:** 3,900
- **Columns:** 18
- **Format:** CSV
- **Missing Values:** 37 missing values in the Review Rating column

### Key Features

- **Customer Demographics:** Age, Gender, Location, Subscription Status
- **Purchase Details:** Item Purchased, Category, Purchase Amount, Season, Size, Color
- **Shopping Behavior:** Discount Applied, Promo Code Used, Previous Purchases, Frequency of Purchases, Review Rating, Shipping Type

## 3. Tools and Technologies

- **Python:** Data cleaning, preprocessing, and exploratory data analysis
- **Pandas and NumPy:** Data manipulation and numerical analysis
- **Matplotlib and Seaborn:** Data visualization
- **PostgreSQL:** SQL queries and business analysis
- **Power BI:** Interactive dashboard and KPI visualization
- **Jupyter Notebook:** Python-based analysis
- **PowerPoint:** Presentation of key findings and recommendations

## 4. Project Workflow

### Step 1: Data Loading and Exploration

- Imported the CSV dataset into Python using Pandas.
- Examined the dataset structure using `df.info()`.
- Generated summary statistics using `df.describe()`.
- Checked for missing values and data inconsistencies.

### Step 2: Data Cleaning and Feature Engineering

- Handled missing Review Rating values using the median rating of the corresponding product category.
- Standardized column names using snake_case.
- Created an `age_group` column by grouping customer ages.
- Created a `purchase_frequency_days` column from purchase data.
- Checked the relationship between `discount_applied` and `promo_code_used` and removed the redundant `promo_code_used` column.

### Step 3: PostgreSQL Integration

- Connected Python to PostgreSQL.
- Loaded the cleaned DataFrame into the database.
- Used SQL queries to analyze customer behavior, revenue, product performance, discounts, and subscriptions.

### Step 4: SQL Business Analysis

The following business questions were investigated:

1. **Revenue by Gender:** Compared total revenue generated by male and female customers.
2. **High-Spending Discount Users:** Identified customers who used discounts but spent above the average purchase amount.
3. **Top 5 Products by Rating:** Identified products with the highest average review ratings.
4. **Shipping Type Comparison:** Compared average purchase amounts for Standard and Express shipping.
5. **Subscribers vs. Non-Subscribers:** Compared average spending and total revenue by subscription status.
6. **Discount-Dependent Products:** Identified five products with the highest percentage of discounted purchases.
7. **Customer Segmentation:** Classified customers into New, Returning, and Loyal segments based on purchase history.
8. **Top 3 Products per Category:** Identified the most purchased products within each category.
9. **Repeat Buyers and Subscriptions:** Examined whether customers with more than five purchases were more likely to subscribe.
10. **Revenue by Age Group:** Calculated the total revenue contribution of different age groups.

## 5. Results and Business Recommendations

The analysis provides insights into customer behavior and supports the following business recommendations:

- **Boost Subscriptions:** Promote exclusive benefits to encourage customers to subscribe.
- **Customer Loyalty Programs:** Reward repeat buyers and encourage them to become loyal customers.
- **Review Discount Policy:** Balance the benefits of discounts with profit margin considerations.
- **Product Positioning:** Highlight top-rated and best-selling products in marketing campaigns.
- **Targeted Marketing:** Focus marketing efforts on high-revenue age groups and customers using Express shipping.

These recommendations connect the analytical findings with potential business actions.
